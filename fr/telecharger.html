VideoGlance a été testé sur macOS 15 Sequoia. Les versions plus récentes de macOS n’ont pas encore été testées, et les Mac équipés d’un processeur Intel ne sont pas pris en charge pour le moment.

Installer VideoGlance

  1. Téléchargez l’image disque VideoGlance-1.1-46-arm64.dmg et ouvrez-la.
  2. Glissez VideoGlance dans le dossier Applications.
  3. Sélectionnez une vidéo MKV dans le Finder et appuyez sur Espace.

Au premier aperçu, ou si vous ouvrez VideoGlance, macOS vous demande de confirmer l’ouverture d’une app téléchargée sur Internet : cliquez sur Ouvrir. Ensuite, il n’y a rien à lancer au quotidien : macOS fait appel à VideoGlance quand vous prévisualisez une vidéo compatible.

Avec Homebrew

Si vous installez déjà vos applications avec Homebrew :

brew install --cask kwadz/videoglance/videoglance

Homebrew ajoute le dépôt de VideoGlance, vérifie l’empreinte de l’image disque et place l’application dans le dossier Applications. VideoGlance n’a besoin d’aucun autre paquet Homebrew.

Mettre à jour ou désinstaller

Pour mettre à jour, fermez les aperçus ouverts, puis remplacez VideoGlance dans le dossier Applications par la nouvelle version. Avec Homebrew : brew upgrade --cask videoglance.

Pour désinstaller, déplacez VideoGlance du dossier Applications vers la Corbeille. Avec Homebrew : brew uninstall --cask videoglance.

Notes de version

VideoGlance 1.1 (46), 29 octobre 2026. Première version publique.

  • Aperçus Quick Look et vignettes du Finder pour les MKV, WebM, FLV/F4V, WMV, OGV/OGM et RMVB.
  • Commandes de lecture, de volume et de vitesse dans la fenêtre Quick Look ; lecture et recherche dans l’anneau du panneau Aperçu.
  • Limites connues : seule la piste audio par défaut est lue, sans sous-titres ; macOS garde ses propres aperçus pour les MP4, MOV, M4V et 3GP, et se réserve les AVI, RM, TS, MTS et M2TS. Voir la section Bon à savoir du guide.

Conditions et logiciels libres

VideoGlance est gratuit pour un usage personnel comme professionnel. Son code n’est pas open source ; il s’appuie sur des bibliothèques libres, dont FFmpeg et libmpv sous licence LGPL. Leurs mentions sont incluses dans l’application, et leurs sources pour cette version (archive de 259 Mo) sont proposées à côté de l’image disque.
